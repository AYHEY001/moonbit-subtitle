# moonbit-subtitle

纯 MoonBit 实现的字幕处理工具库：解析、变换、渲染 SRT 与 WebVTT。

当前是早期开发阶段，为 2026 MoonBit 九月黑客松而建。API 尚不稳定。

## 这个库解决什么问题

SRT 看起来是个简单格式，实际上从字幕组、剪辑软件、在线平台导出的文件里
混着不少脏东西：

- 文件开头的 UTF-8 BOM
- Windows 的 CRLF 换行
- 序号跳号、乱序、重复
- 相邻字幕时间重叠几十毫秒，部分播放器会闪烁或丢行
- 时间行两侧多余空格

现成的字幕工具大多假设输入是干净的，一遇到这些就出错或者静默丢字幕。
这个库的目标是：**尽量把能救回来的文件救回来，明确地说出哪些救不回来。**

## 构建与测试

需要先安装 MoonBit 工具链（见 https://www.moonbitlang.com/download/）
与 VS Code 的 MoonBit 插件。

```
moon check          # 类型检查
moon build          # 构建
moon test           # 跑测试
moon test --update  # 重写 inspect(...) 里的期望值
moon run cmd/main   # 运行命令行程序
```

`moon test --update` 在写快照测试时很有用：先写 `inspect(实际值)`，
跑一次让它把期望值填进去，再人工核对一遍。核对这一步不能省。

## 设计决定

**时间统一用毫秒整数。** 用浮点秒数做平移和缩放会有累积误差，
长视频里最后几行字幕会明显漂移。

**手写字符串切分，不用正则。** MoonBit 核心库没有内置正则表达式支持，
`moonbitlang/regexp` 目前仍是 alpha。时间戳解析的规则足够简单，手写切分更可控。

**对外的数据类型用 `pub` 而非 `pub(all)`。** 其他包可以读取字段和模式匹配，
但不能凭空构造。合法的时间值只能通过解析函数产生，校验逻辑因此只有一个出口。

**零第三方依赖。** 解析和变换只用核心库。引入依赖会带来版本兼容负担，
而这个库要处理的东西不值得付出这个代价。

## 支持范围

计划支持：

- SRT 的解析与渲染
- WebVTT 的解析与渲染
- 时间轴平移、倍速缩放、重叠合并、重新排序

明确不做：

- 字幕格式转换以外的视频容器操作
- 机器翻译
- 图形界面
